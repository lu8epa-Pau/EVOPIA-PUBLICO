EVOPIA COMPLETA 1.0
Incluye PTT real, audio WebRTC, hasta 10 operadores, instructor/cursantes, lista, registro y guía de QSO.
Requiere Node.js 18+: ejecutar npm install y npm start; abrir http://localhost:3000.
Para Internet se requiere HTTPS/WSS. STUN está incluido; TURN puede ser necesario en algunas redes.
